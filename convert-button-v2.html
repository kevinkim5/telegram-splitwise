Behaviour changes in this version
• Target is always SGD. It no longer follows the group's default currency (which now only sets the currency pre-selected when adding a new expense).
• The control appears only when at least one balance is in a currency other than SGD; the banner lists those currencies.
• Wording: "Convert to SGD" → "Showing ≈ SGD" + "Show original". The button label always says what tapping it will do.
• Rates still fetched only on first tap, then toggled locally. Banner shows the rate date (ECB publishes once per business day, so "today's rate" may be yesterday's close — stating the date avoids the "looks delayed" confusion).
